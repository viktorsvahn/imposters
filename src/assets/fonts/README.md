# Fonts included with Imposters

All of them may be used, embedded (PDF, HTML) and redistributed freely, also commercially.

| Family | Files | Licence | Source |
|---|---|---|---|
| TeX Gyre Heros, TeX Gyre Termes | `texgyreheros-*`, `texgyretermes-*` | GUST Font License (`GUST-FONT-LICENSE.txt`) | CTAN `fonts/tex-gyre` |
| Latin Modern Roman, Sans, Math | `lmroman10-*`, `lmsans10-*`, `latinmodern-math` | GUST Font License | CTAN `fonts/lm`, `fonts/lm-math` |
| IBM Plex Mono (Latin) | `plexmono-*` | SIL Open Font License 1.1 (`OFL-IBM-Plex.txt`) | IBM Plex via Fontsource |

The OpenType files were converted to WOFF2 unchanged (fontTools).
